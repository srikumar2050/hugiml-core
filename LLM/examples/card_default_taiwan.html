Key findings from this session

Cardholder file · 8000-account session sample · 8-rule model

  • No single month of being late predicts default well on its own -- the signal only emerges across two cycles.
  • Moving from single-month to paired-month rules lifted AUC to 0.708 at the same 12-rule budget.
  • Tuning for recall caught 0.509 of defaults instead of 0.310.
  • Trimming to 8 rules for the daily batch job changed AUC by 0.001.

In short: repayment trajectory, not a single snapshot, is what actually predicts default here.
