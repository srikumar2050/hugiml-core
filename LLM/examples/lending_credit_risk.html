Key findings from this session

Consumer loan portfolio · 1000 applications · 8-rule model

  • checking_status=< 0 DM is the single strongest signal in the model.
  • A 12-rule model already reaches 0.718 AUC; wider rule sets do not reliably score higher.
  • Weighting the loss toward bad-risk applicants moved the catch rate from 0.347 to 0.773.
  • Trimming to 8 rules for sign-off changed AUC by 0.000.
  • Every flagged application traces back to a short, named list of rules.

In short: a short, auditable rule set that's tunable to the bank's actual risk appetite.
