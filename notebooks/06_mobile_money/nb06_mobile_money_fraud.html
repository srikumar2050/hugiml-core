01Extreme Class Imbalance — Key Choices0.13% fraud
Primary metric is Average Precision, not AUC-ROC. At 0.13% fraud rate, the vast TN pool inflates ROC-AUC — even a near-random model can achieve AUC > 0.99. AP measures the precision-recall trade-off across all thresholds and is robust to class imbalance.

Modeling Choices

  • 📊 Primary metric: Average Precision (AP)
  • ✂️ 50,000 row subsample (65 fraud; ~13 per split)
  • 📅 60/20/20 train / calibration / test
  • ⚠️ Isotonic calibration with ~13 cal. positives = high variance
  • 🔑 Threshold selection via F1-maximisation on PR curve
