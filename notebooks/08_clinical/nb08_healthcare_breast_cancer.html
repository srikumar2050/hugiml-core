Audit-review dashboard for malignancy-risk triage using a public benchmark clinical dataset. The evidence emphasizes measured model behavior, patient-level interpretability, safety review, and documented limitations.

Use case: diagnosis-assistance triage
Dataset: Wisconsin Diagnostic Breast Cancer
Holdout review: 171 cases
Decision boundary: clinician review; not autonomous diagnosis
1Executive Evidence Summary

The holdout results show strong discrimination with a small number of safety-critical misses. The governance decision is therefore not whether the model is merely accurate, but whether the threshold, explanation record, subgroup limits, and monitoring controls are sufficient for supervised clinical triage.

3Clinical Validation Results
Confusion matrix is reported at the operating threshold, not just at an arbitrary default, because false-negative tolerance is a governance decision.

Validation comments

Sensitivity: 92.2%; specificity: 100.0%; precision: 100.0%.

The low false-positive count suggests limited benign over-escalation on this holdout split, while the false-negative count remains the key clinical safety review sample.

For an audit committee, the relevant record is the threshold rationale plus evidence that discordant cases were reviewed, not a single aggregate performance score.

4Probability Quality: Discrimination and Calibration
AUC confirms the model separates malignant and benign cases well in this benchmark split.
Calibration is retained because review teams may use scores to prioritize cases, not only accept binary escalation.
Threshold comment. A review threshold of 0.72 was selected from training data to preserve at least 95% malignant sensitivity.
Calibration comment. Brier score of 0.017 indicates low probability error on the holdout split, but local calibration must be rechecked in deployment populations.
Use limitation. Good calibration on a benchmark does not prove calibration in a hospital-specific EHR workflow.
5Dominant Model Drivers
Driver direction is based on standardized model coefficients; variables shown have the largest absolute influence on malignant-risk scoring.

Interpretive summary

The strongest model drivers are morphology variables related to perimeter, radius, texture, concavity, and concave points. This is consistent with the dataset design: the model is learning tumor shape and boundary irregularity rather than administrative or demographic proxies.

This section supports independent clinical review because drivers can be mapped back to measured tumor characteristics.

6Transparent Pattern Evidence

Patterns below are computed from training-cohort quartile bands. This creates regulator-reviewable evidence: each pattern has a case count, support, observed malignant rate, and lift versus the training baseline.

The plot uses concise clinical-band labels to avoid overplotting. The strongest pattern is worst perimeter in Q4 high, with 2.66× malignant-rate lift.

Evidence interpretation

High-risk bands concentrate malignant observations in upper morphology ranges. This is useful for governance because reviewers can see the empirical basis for the alert rather than a generic importance ranking.

Patterns with low support should not be used as standalone clinical rules. The table preserves support and case count so reviewers can distinguish robust patterns from sparse findings.
