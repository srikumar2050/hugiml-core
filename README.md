# HUGIML Interactive Demos

Explore HUGIML through interactive dashboards, guided video demonstrations, and LLM-based model-review examples.

**Live site:** https://srikumar2050.github.io/hugiml-core/

## Interactive dashboards

### Benchmark analysis

- [Benchmark Analysis Dashboard](https://srikumar2050.github.io/hugiml-core/hugiml_benchmark_analysis_dashboard.html) — real and synthetic benchmark analysis across predictive quality, timing, robustness, and model complexity.
- [OpenML-CC18 Benchmark Dashboard](https://srikumar2050.github.io/hugiml-core/openml_cc18_benchmark_dashboard.html) — evaluation on OpenML-CC18 tasks using official task splits and matched comparisons.
- [TabZilla Benchmark Dashboard](https://srikumar2050.github.io/hugiml-core/tabzilla_benchmark_dashboard.html) — matched TabZilla benchmark analysis.
- [PMLBmini Benchmark Dashboard](https://srikumar2050.github.io/hugiml-core/pmlbmini_benchmark_dashboard.html) — PMLBmini binary-classification benchmark.
- [TabArena Official Leaderboard](https://srikumar2050.github.io/hugiml-core/tabarena_official_leaderboard_dashboard.html) — official-reference Elo and metric comparisons.
- [Scalability Dashboard](https://srikumar2050.github.io/hugiml-core/hugiml_scalability_dashboard.html) — fit-time and inference-latency scaling across data size and dimensionality.

### Governance

- [Governance Studio Demo](https://srikumar2050.github.io/hugiml-core/hugiml_governance_studio_demo.html) — validation, representation review, data-quality analysis, monitoring, and case-level explanation views.
