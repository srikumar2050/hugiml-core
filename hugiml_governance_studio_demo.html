HUGIML

High-utility pattern learner with explicit pattern provenance, augmented-pair scoring, survivor-led pattern audit, and adaptive binning enabled by default; adaptive-binning sample selection is available in Advanced mode.

Guided fast tuning uses a named HUGIML grid. The performance grid is selected by default; the interpretability grid uses pattern-only downstream features and interaction-relaxed mining.

Searches original-plus-pattern features across L, topK, and G for predictive performance.

Advanced can tune augmented-pair scoring, adaptive-binning sample selection, or interaction-relaxed mining explicitly. Guided keeps the selected named grid.

For L≥2, Advanced omits candidates that enable augmented-pair transforms and interaction-relaxed mining at the same time. Adaptive-binning sample selection is independent of the interaction path and keeps full-data fitting after bin edges are selected.

Survivor-led audit is split into two levels: source features selected by interaction-relaxed mining, and ordinary original-feature interval patterns that use those sources. Source-feature partner details are shown only in the feature-level table.
What is a survivor? A survivor is an original feature that may not have enough marginal information gain on its own, but is kept because its interaction-information score with another feature shows useful pair context. The mined output remains an interpretable original-feature interval pattern.
